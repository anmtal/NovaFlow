# NovaFlow

AI-powered lead conversion website with Stripe checkout.

## Files
- index.html
- server.js
- package.json
- logo.png
- success.html
- .env.example
- README.md

## Setup
1. Copy `.env.example` to `.env`
2. Add your Stripe keys and local domain
3. Put your PNG logo in the folder as `logo.png`
4. Run `npm install`
5. Run `npm start`
